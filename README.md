# Java Básico - DAW 🚀

Colección de ejercicios prácticos de Java desarrollados durante el ciclo formativo de **Desarrollo de Aplicaciones Web (DAW)**.

## 🛠️ Características del Proyecto
* **Lenguaje:** Java (compatible con versiones modernas / Java 25+ utilizando sintaxis simplificada `void main()`).
* **Enfoque:** Lógica de programación, estructuras de control, operadores y tipos de datos.
* **Automatización:** Procesado y estructurado mediante scripts de Node.js para la gestión limpia del código fuente.

## 📁 Contenido
El repositorio incluye ejercicios prácticos resueltos desde los fundamentos básicos (variables, operadores, conversión de tipos con `IO.readln`) hasta estructuras de decisión y validaciones lógicas (`Ejercicio01.java` al `Ejercicio30.java`).
